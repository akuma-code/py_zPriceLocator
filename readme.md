Программа для получения цены жалюзи

Входные данные:
ширина - w;
высота - h;
тип - isolite/viteo;
название - label;
цвет короба - белый, коричневый, серебро, бежевый, махагон - korob;

Вывод:
список карточек в которых отображается цвет, тип, цвет короба, размеры и цена. Карточку можно редактировать.

Основная логика:
Размеры округляются до 1 знака после запятой, после чего сопостовляются с таблицей цен. 
Для получения таблицы цен нужно открыть прайс с расширением .xls или .xlsx, после чего найти таблицу с ценовой группой и из нее получить цену.
Список соответствия названий с ценовой группой прописаны в файле groups.json, в виде {{тип1: {группа:[название1, название2]}}, {тип2: {группа:[название1, название2]}}} который лежит в корне проекта.
Расположение таблицы с ценой в прайсе прописаны в файле adresses.json в виде {тип:[{группа:[[rowStart, colStart], [rowEnd, colEnd]]}]}

Интерфейс программы:
блок ввода:
сетка 4х2
верхний ряд - кнопка смены типа isolite/viteo, выпадающий список с названиями (label), выпадающий список с цветами короба
нижний ряд - поле ввода ширины, поле ввода высоты, кнопка добавить
справа от сетки - меню настроек, в которых можно указать расположение прайса и запустить тест. Тестирование проверяет наличие прайса по указаному пути, а также то, что по адресам из файла adresses.json в прайсе есть данные, а не пустые ячейки.

блок вывода:
список карточек 
вид карточки - [[тип] [название] [цвет] [короба] - [размеры]  цена | [редкатировать][удалить]]

Дополнительно:
Структура данных в файлах groups и adresses может быть изменена на более удобную
